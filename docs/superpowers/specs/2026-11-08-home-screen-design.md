# Главный экран Minimal Launcher — дизайн

Дата: 2026-11-08  
Статус: ожидает утверждения

## Цель

Создать первую версию минималистичного главного экрана Android-лаунчера: время и дата, свободное пространство и пять избранных приложений внизу. Экран должен стать основой для последующего добавления поиска, папок, настроек и сохранения избранного.

## Состав и поведение

- Крупные часы располагаются в верхней части экрана; под ними отображается текущая дата.
- Время и дата учитывают системные настройки времени, часового пояса и локали.
- Центральная часть экрана остаётся свободной.
- Внизу расположен один горизонтальный ряд из пяти равномерно распределённых монохромных иконок.
- На первом этапе иконки — временные заглушки. Выбор и сохранение реальных приложений добавляются позднее.
- Экран имеет однотонный фон и использует тему Material 3; полноценная настройка светлой/тёмной темы не входит в этот этап.
- Приложение регистрируется в Android как возможный Home Launcher, чтобы его можно было выбрать в системных настройках.

## Архитектура

Использовать Kotlin, Jetpack Compose и существующую структуру проекта с MVVM:

- `HomeScreen` — отображает интерфейс на основе состояния и не содержит бизнес-логики.
- `HomeViewModel` — предоставляет состояние главного экрана через `StateFlow`.
- UI собирает состояние lifecycle-aware способом.
- Обновление времени выполняется с периодичностью, достаточной для отображения часов; дата обновляется вместе с ним. Системные изменения времени/часового пояса должны учитываться.
- На этом этапе не добавлять Room, DataStore или новые зависимости без необходимости. Сохранение избранного и настройки — отдельная последующая задача.

## Подходы, рассмотренные при выборе

1. **Простой Compose-экран без ViewModel.** Меньше кода на старте, но состояние и дальнейшее расширение экрана быстро смешаются с UI.
2. **Compose + MVVM + StateFlow (выбран).** Немного больше начального кода, зато интерфейс отделён от состояния и проще расширяется. Этот подход соответствует архитектуре проекта и остаётся достаточно простым для поддержки.

## Не входит в этот этап

- Реальное получение списка установленных приложений и запуск приложений по нажатию.
- Выбор, перестановка и сохранение избранных приложений.
- App Drawer, папки, поиск и жесты.
- Виджеты, анимации и экран настроек.
- Полноценная система тем и кастомизация сетки.

## Критерии готовности

- Проект собирается без ошибок.
- Главный экран отображает часы, дату и пять заглушек внизу.
- Время обновляется без перезапуска экрана.
- Экран корректно располагается на разных размерах экранов и не перекрывается системными областями.
- Приложение доступно Android для выбора в качестве приложения Home.
